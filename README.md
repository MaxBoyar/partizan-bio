# ❄️ Partizan — Gaming Link-in-Bio Hub

עמוד קישורים ופרופיל גיימר מקצועי עבור **Partizan** בעיצוב חורפי-עתידני (Winter Esports Gaming Hub) עם תמיכה מלאה בעברית ו-RTL.

---

## 🎮 מאפיינים ועיצוב (Features & Design)

1. **מיתוג וצבעים בהשראת לוגו Partizan**:
   - פלטת גוונים מבוססת קרח ונייבי: כחול קרח כהה, כחול נייבי עמוק, ציאן זוהר (`#00b4ff`), ואפקט זוהר קרח.
   - Dark Mode בלבד ללא צבעים חמים.
   - לוגו Partizan משובץ בראש העמוד בתוך מסגרת מגן גיימינג מוארת עם תג אימות (Shield Star Badge).

2. **תמיכה מלאה בעברית (RTL)**:
   - כיוון קריאה מלא מימין לשמאל (`dir="rtl"`).
   - טיפוגרפיה מודרנית עם גופני Google Fonts: **Heebo**, **Rubik**, ו-**Orbitron**.
   - כותרות ותיאורי קישורים בעברית טבעית וקולחת.
   - חיצי ניווט מכוונים שמאלה בהתאמה לתנועת RTL.

3. **אפקט שלג מתקדם (Dynamic Snowfall Effect)**:
   - יישום מדויק לפי מפרט הבקשה:
     - גדלים רנדומליים (`0.25vw` - `1.15vw`)
     - תנועה אופקית מותאמת אישית לכל פתית (`--left-ini`, `--left-end`)
     - משך נפילה משתנה (5–15 שניות)
     - עומק שדה (טשטוש `blur(1.5px)` לחלק מהפתיתים)
     - דיליי שלילי כך שהשלג מפוזר במסך מיידית בטעינה.
     - רץ בשכבה אחורית (`pointer-events-none -z-10`) ללא פגיעה בביצועים.

4. **כרטיסי קישורים גיימינג פרימיום**:
   - Twitch (כרטיס VIP מודגש עם תג Live וזוהר ניאון)
   - ערוץ YouTube רשמי
   - שרת Discord עם קהילה פעילה
   - TikTok (קליפים ורגעי שיא)
   - Instagram (סטוריז ומאחורי הקלעים)
   - X / Twitter (חדשות וסקרים)
   - חנות מרצ'נדייז רשמית (קולקציית חורף)
   - פרופיל Steam
   - ערוץ Kick (שידורי לילה)
   - פניות עסקיות וחסויות

5. **פיצ'רים אינטראקטיביים נוספים**:
   - **לוח שידורים שבועי (Schedule Modal)**: מודאל שעות וימי שידור קבועים לפי שעון ישראל.
   - **מפרט מחשב וציוד גיימינג (Rig Specs Modal)**: מעבד, כרטיס מסך RTX 4080 Super, מסך 360Hz, מקלדת Wooting 60HE, מיקרופון SM7B ועוד.
   - **אווירת סאונד מובנית (Web Audio API)**: אפקט לחיצה קריסטלי וצליל משב רוח חורפי עדין (ללא קבצי אודיו חיצוניים).
   - **העתקת קישור מהירה ושיתוף**: לחצן שיתוף מובנה עם הודעת Toast בעברית.

## 🚀 הרצה ופיתוח (Getting Started)

הפרויקט בנוי ב-**React 18 + Vite + Tailwind CSS**.

### הרצת שרת פיתוח:
```bash
npm run dev
```

### בניית גרסת Production:
```bash
npm run build
```
התוצר יישמר בתיקיית `dist/` ומוכן לפריסה ב-Vercel, Netlify, Cloudflare Pages או GitHub Pages.

### גרסה עצמאית (Standalone):
ניתן לפתוח ישירות את הקובץ `standalone.html` בכל דפדפן בדאבל-קליק ללא צורך בהתקנות.
